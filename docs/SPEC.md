# 旅遊記帳 App 規格書(SPEC)

> 本文件整理自前期討論,是開發的唯一依據。已定案的決定不需再討論;「待決定」區的項目遇到時再問使用者。
> 語言:與使用者溝通一律使用繁體中文。

## 1. 專案定位

- 個人自用的 Android 旅遊記帳 App,**不上架**。iPhone 版由家人另外在 Mac 上移植(見 `docs/IOS_PORT.md`),檔案格式共用。
- 技術:**Kotlin + Jetpack Compose + Room**(單 Activity、MVVM、Material 3)。
- 資料全部存手機本機,**離線優先,不做雲端同步、不做多人共同記帳**。
- 目標是精緻、順手:旅途中記一筆要在三步內完成。

## 2. 核心概念

**以「旅程」為最上層容器。** 每趟旅程是獨立的資料,新旅程從零開始,舊旅程永遠可查詢、可統計、可搜尋。

旅程屬性:名稱、起訖日期、旅行人數(成員名單)、主要結算幣別(本國幣)、旅程預設匯率(依外幣)、預算(選填)、是否啟用分帳(每趟各自設定)。

## 3. 已定案的設計決定

### 3.1 分帳(每趟旅程獨立開關)
- 資料結構一開始就保留「付款人、分攤對象」。
- 開關**關閉**(家人旅遊的預設):記帳畫面不顯示付款人/分攤欄位,預設等同「一人付、全員均攤」。
- 開關**開啟**(與朋友旅遊):顯示「誰付的、誰分攤」,並提供結算頁(自動算出誰該付誰多少)。
- 中途開啟不得破壞舊資料。

### 3.2 外幣與匯率
- 每筆支出保存:原幣金額、幣別、匯率、換算後本國幣金額。
- 匯率來源:旅程預設值,**可逐筆修改**(實際換匯/刷卡匯率常與參考匯率不同)。
- 提供「一鍵抓取匯率」:抓一次存起來,新建旅程時抓一次當預設,有網路時可手動更新;**失敗或離線不影響記帳**,沿用上次的值。
- 手動輸入必須永遠可用。
- API 選用免費、需確認含本國幣、離線可降級;選定前先查最新條款。(見待決定)

### 3.3 記帳要快
- 大數字鍵盤輸入金額;幣別、付款方式、付款人預設帶上一筆的值。
- 備註、照片皆選填。

### 3.4 分類
- **分類是可自訂清單,不寫死**。使用者尚未定案分類,預設預置少量(交通、住宿、購物、吃、其他),可新增/改名/刪除/排序。
- 刪除正在使用的分類時要有處理(改歸「其他」)。

### 3.5 其他支出欄位
- 每筆支出有**獨立日期**(機票、住宿常在出發前付款,統計需能涵蓋旅程期間以外的預付費用)。
- 付款方式:現金、信用卡、行動支付(可編輯清單)。

### 3.6 支出資料欄位(Expense)
日期、金額(原幣)、幣別、匯率、本國幣金額、分類、付款方式、付款人、分攤對象、備註、照片(0 到 3 張)。

## 4. 照片功能

### 4.1 拍攝流程
- 記帳畫面一個相機圖示,點一下拍一張(使用系統相機,一次一張),回到記帳畫面顯示縮圖與「還能拍 N 張」。
- **每筆最多 3 張**,拍滿後圖示變灰。
- 長按縮圖:刪除、重拍、切換類型。

### 4.2 類型標籤:收據 / 回憶
- 每張照片有類型:📄收據(含菜單、價目表)或 🖼回憶(食物、風景等)。
- **自動判斷**:拍完用 ML Kit 文字辨識(離線、免費)掃描原圖,依「文字行數多、含大量數字與價格、含合計/Total/税/レシート 等關鍵字」判為收據,**不確定時預設回憶**。
- **一鍵改正**:點縮圖角落標籤即可切換。
- 備案:若實測準確度不足,改為相機旁兩個按鈕「📄拍收據」「📷拍照留念」,使用者自行選擇。
- 文字辨識需涵蓋中、日、韓、拉丁文字(各自模型,需實測準確度)。
- 辨識使用**剛拍完的原圖**,辨識完才壓縮存檔。

### 4.3 儲存
- 照片存 App **私有資料夾**,**收據與回憶分資料夾**;資料庫只存檔案路徑與類型,不存圖本身。
- 壓縮:收據長邊約 1600、回憶長邊約 1200(約 300 KB/張)。
- 刪除支出時一併刪除照片。
- 使用系統拍照/相簿選取,盡量不跳額外權限詢問。

### 4.4 另存相簿(兩類各自獨立開關)
- **回憶**:預設**自動另存**手機相簿,並保留較高畫質(本來就是留念)。
- **收據**:預設**不存**相簿。
- 每張照片提供手動「存到相簿」,單張或整趟皆可。

### 4.5 空間管理
- 設定頁顯示照片總佔用,可依旅程檢視。
- 「清除某趟旅程的照片、保留帳目」。
- (之後)「舊旅程瘦身」:一年前的旅程照片再壓縮到長邊約 800。

## 5. 統計與查詢

**單趟旅程**:總花費、日均、人均、依分類/日期/付款方式的圖表、預算使用進度。
**跨旅程**:各趟總額與人均比較、同國家不同次的花費對照。
**搜尋**:全文搜尋備註與分類(例如「拉麵」)。
**匯出**:CSV 或 Excel,供回電腦整理。

## 6. 備份與還原

- 匯出單一 zip:選「含照片」或「只備份帳目」。
- 可匯入 zip 還原(換手機、重裝時使用)。
- 不做雲端同步。

## 7. 資料表草案(Room)

- `Trip`:id、name、startDate、endDate、homeCurrency、budget、splitEnabled、createdAt、archived
- `TripCurrencyRate`:tripId、currency、rate、updatedAt、source(manual/auto)
- `Member`:id、tripId、name
- `Category`:id、name、sortOrder、(是否全域共用,見待決定)
- `PaymentMethod`:id、name、sortOrder
- `Expense`:id、tripId、date、amount、currency、rate、homeAmount、categoryId、paymentMethodId、payerId、note、createdAt
- `ExpenseShare`:expenseId、memberId(分攤對象;分帳關閉時預設全員)
- `Photo`:id、expenseId、type(RECEIPT/MEMORY)、path、width、height、createdAt、savedToGallery

## 8. 開發階段(每階段結束都要能編譯、執行、驗證)

1. **骨架**:專案設定、Room 資料庫、旅程新增/列表/進入、設定頁基礎。
2. **記帳核心**:支出新增/編輯/刪除、金額鍵盤、幣別與匯率(手動)、分類與付款方式管理。
3. **統計**:單趟統計與圖表、預算進度、搜尋。
4. **分帳**:每趟開關、付款人/分攤、結算頁。
5. **照片**:拍照、壓縮、分資料夾、縮圖、類型標籤(先手動切換)。
6. **文字辨識**:ML Kit 自動判斷類型、一鍵改正;實測準確度,必要時改兩按鈕備案。
7. **匯率抓取**:一鍵抓取、失敗降級。
8. **備份與匯出**:zip 備份還原、CSV/Excel 匯出。
9. **跨旅程比較、空間管理、相簿另存、細節打磨**。

之後再考慮:收據金額自動辨識、每趟照片牆、舊旅程瘦身。

## 11. 第一輪改版(已完成,v0.4.0;v0.5.0 依試用回饋調整)

- **套件識別碼**改為 `com.archiekuo.travelledger`(需移除舊版重裝)。
- **字體**:大小適中,內文 16sp 起;設定頁「字體大小」標準/大/特大,並跟隨系統字體。省空間靠減少留白與重複標籤,不縮小字。
- **記一筆**(單一頁面):
  - 最上方「名稱」(店家/項目),輸入時提示過去用過的名稱,選了自動帶分類;另有可展開的小「備註」。
  - 日期+時間自動帶現在時間,點了可改。
  - 順序:名稱 → 分類(一行可橫滑)→ 付款方式(一行)→ 金額。
  - 計算機約半個螢幕,幣別在計算機上切換;匯率以小字顯示,點了可改。
- **拍照與收據辨識**:相機/相簿,每筆最多 3 張;ML Kit 離線辨識(中、日、韓、英模型全部包進 APK);自動判斷收據/回憶;收據自動填店家、金額、幣別、日期時間,使用者確認後套用;辨識文字存起來供搜尋;列表顯示縮圖;照片預覽可切換類型、刪除、存相簿。
- **首頁邏輯**:有進行中旅程(含 30 天內出發)時直接開該旅程;點旅程名稱回旅程列表。
- **旅程主頁**:總花費卡 + 分類統計(點分類篩選明細)+ 依日期分組明細;成員與匯率移到編輯旅程頁。
- **封面**:只從相簿選(自動找圖試用後取消,App 不需網路權限)。
- **作者與版本**:旅程列表標題「卡溜趴 v版本 ArchieKUO」(金色斜體),設定頁「關於」也有。
- **拍照三個按鈕**:拍收據(辨識、不存相簿)/拍照(不辨識、同時存相簿)/相簿(自動判斷)。
- **桌面圖示**:使用者提供的行李箱圖。
- 介面依 `docs` 中的設計稿風格,每個畫面以淺色/深色/特大字截圖檢查。

## 13. 第三輪(已完成,v0.7.0):簽章、備份、分享給同伴

- 決定:先把 Android 版做完整,iPhone 版之後重建;不做雲端同步,改為「一個人記帳,用 LINE 分享檔案給同伴看」。
- 正式簽章金鑰:沿用已安裝版本的金鑰(SHA-256 `661000B5…30F4`),金鑰檔不放 repo;建置時檢查指紋,不符就停止。雲端建置透過環境變數 `TRAVEL_LEDGER_KEYSTORE_B64`(金鑰 base64)提供,本機用 `local.properties` 的 `travelLedger.keystore`。
- 檔案格式(.zip):`manifest.json`(format/version/kind/sharedBy/匯出時間/旅程摘要)+ `data.json`(旅程、成員、匯率、行程、支出;分類與付款方式用名稱對應)+ `files/`(照片、封面,選擇性)。

- 備份:全部旅程,含照片可選;還原時同 uuid 取代、其他保留;缺少的分類與付款方式補上。
- 唯讀 UI:旅程上方顯示「唯讀 · X 分享 · 時間」,隱藏記一筆/新增/編輯/打勾,支出與行程以明細頁顯示。
- 開啟方式:LINE「用其他應用程式開啟」(VIEW)、分享到卡溜趴(SEND)、設定「從檔案還原或匯入」。
